# Nexus LLM Gateway 产品手册

## 1. 产品定位

Nexus LLM Gateway 为企业应用提供稳定的模型别名、统一身份、路由治理、审批发布、调用追踪、用量成本和审计能力。应用只依赖 `smart-chat` 等稳定别名，网关按活动快照选择实际提供商端点。

核心原则：

- 控制面负责策略编辑、职责分离审批、编译和发布。
- 数据面只读取活动的不可变快照，避免半发布状态。
- 策略按“全局 → 别名 → 应用 → 应用+别名”逐层覆盖。
- 重试仅允许发生在首字节发送前，总尝试次数最多 3 次。
- 每次调用保存逻辑请求、端点尝试、快照、用量和成本。

## 2. 启动产品

```bash
cd code-app/backend
python -m venv ../.venv
../.venv/bin/pip install -r requirements.txt

cd ../frontend
npm ci
npm run build

cd ../backend
../.venv/bin/python app.py
```

打开 <http://127.0.0.1:5000>。演示环境无需登录，默认数据包括：

- 应用：`research-copilot`
- 模型别名：`smart-chat`
- 主端点：`openai-primary`
- 灾备端点：`azure-fallback`
- 活动快照：页面顶栏和总览页可见

## 3. 界面说明

界面采用三栏工作台：左侧导航、中央业务区、右侧 AI 运维助手。

| 菜单 | 用途 |
|---|---|
| 运行总览 | 查看今日请求、成功率、平均时延、成本、活动快照与端点健康 |
| 请求追踪 | 按请求查看快照版本及每次端点尝试、错误和时延 |
| 应用与凭证 | 查看应用负责人、数据等级、额度和预算 |
| 模型别名 | 查看稳定模型名称及能力集合 |
| 提供商端点 | 查看提供商、实际模型、区域、优先级与健康状态 |
| 路由策略 | 查看策略、尝试上限、审批和发布状态 |
| 限额与预算 | 查看应用日额度和月预算 |
| 价格管理 | 查看端点输入/输出单价 |
| 健康与熔断 | 查看端点健康、时延与熔断语义 |
| 对账差异 | 查看内部账单与供应商账单的差异率 |
| 审计日志 | 查看结构化控制面和调用事件 |

## 4. 验证一次主备切换

1. 进入“运行总览”。
2. 点击“发送验证请求”。
3. 演示请求令主端点在首字节前返回 `UPSTREAM_503`。
4. 网关依据活动快照选择灾备端点，并在第二次尝试成功。
5. 进入“请求追踪”，查看同一 `traceId` 下的两次尝试：
   - 第 1 次：`openai-primary`，FAILED；
   - 第 2 次：`azure-fallback`，SUCCEEDED。
6. 总览中的请求量、成功率、时延和成本同步更新。

## 5. 使用 AI 运维助手

在右侧输入“解释最近一次请求为什么发生重试”，点击发送。助手通过 SSE 顺序返回：

1. `reasoning`：解析语义问题；
2. `reasoning`：执行只读关联查询；
3. `answer`：说明首字节前错误、灾备接管和尝试上限；
4. `done`：结束本次回答。

当前助手使用确定性回答验证交互协议；生产化时可把只读本体查询结果作为上下文接入真实 LLM。

## 6. 策略发布流程

可通过 API 验证完整流程：

```text
DRAFT
  → SECURITY_REVIEW（提交）
  → SRE_REVIEW（安全审批）
  → APPROVED（SRE 审批）
  → PUBLISHED（编译并激活快照）
```

约束：提交人不能审批自己的策略；安全和 SRE 必须为不同审批人；未完成审批、没有健康端点时禁止发布。发布成功后生成新的 `snap-*` 版本，旧活动快照失活，并保存多可用区 ACK 摘要。

## 7. 数据与审计

- 默认数据库：`code-app/backend/data/app.db`。
- SQLite 启用 WAL；自动建表和种子数据均具备幂等性。
- 策略和调用操作记录到 `audit_logs`，详情为 JSON 对象。
- 测试通过 `APP_DB_PATH` 使用临时数据库，不污染演示数据。

## 8. 常见问题

**页面显示旧版本？** 先在 `frontend` 执行 `npm run build`，再刷新 Flask 页面。

**验证请求提示没有活动策略？** 检查 `research-copilot`、`smart-chat` 和活动快照是否存在；重新使用空数据库启动可恢复种子数据。

**为什么首字节后不重试？** 流式响应一旦向客户端发送首字节，再切换端点会产生重复或拼接内容，因此 R007/R008 明确禁止。

**如何重置演示数据？** 停止服务后备份并删除 `backend/data/app.db`，再次启动会重建。该操作会清除本地演示数据。

## 9. 当前版本边界

这是面向架构验证和产品评审的快速可运行版本。真实模型网络调用、密钥托管、分布式配额、持久化消息队列与多节点快照分发尚未接入；对应对象、规则、流程和扩展点已记录在本体与功能矩阵中。
