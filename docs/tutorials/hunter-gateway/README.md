- 阅读顺序：第 01 境 → 第 18 境，与仓库分支 `chapter/NN-*` 一一对应。
- 每章一个目录，内含该章的技术文章与视频脚本。
- 素材主键与导出时间见 [`_source-manifest.md`](./_source-manifest.md)。
